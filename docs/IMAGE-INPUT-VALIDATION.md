# Image input validation

SillyTavern plugin 0.10.0 passed two live Gemini 4 Argon requests with lossless WebP pages and progressive text. See the [plugin backend timings](VALIDATION.en.md).

Release 0.6.0 adds an independent text-to-image encoder inspired by Antigravity experimental imagectx, not a Go port. In 0.6.0 it produced PNG pages; current versions produce lossless WebP pages. Renderer and policy tests cover role preservation, latest-turn selection, existing media/tool contracts, pagination, glyph coverage, cancellation, bounds and fixed diagnostics. HTTP mocks cover compatible/native requests, restored SSE, errors without upstream calls and settings persistence. Browser checks used synthetic settings and confirmed image/Unicode mutual exclusion; they are not production configuration changes.

A bounded live check used this gateway with a temporary local OpenAI-compatible relay to Vertex, not this gateway's own authentication path (no settings writeback): one image-encoded synthetic prompt, SSE, 1024 output-token limit. HTTP 200, exact Chinese/ASCII/digit/XML-like transcription, finish=stop, DONE=true, tool-transport-buffered-fields, 1185 prompt tokens and 50 completion tokens, 4531 ms. This verifies the compatible relay path, not direct Express/Flex authentication, long conversations, visual reasoning quality, or installed SillyTavern UI persistence. That gateway check used PNG pages. No progressive delivery or reduced-filtering claim.

System and developer instructions stay in text. Tabs expand to four spaces and CRLF/CR becomes LF. Noto Sans CJK renders text and Noto Color Emoji renders emoji sequences as single graphemes. The regression suite decodes the resulting WebP pages for ❤, ❤️, ♥️, 🙂, 💖, ⚽, 👩‍💻, 👍🏽, 1️⃣ and 🇨🇳 in both input scopes. Controls, malformed sequences and uncovered glyphs return the message-part path and code point. License texts ship alongside both fonts.
